# L3 调度、操作与当前边界

## 固定时间

ReminderPlanner 是纯核心逻辑，接收当前 UTC 时刻、本地时区、开始观察时刻和任务/检查/调度进度快照。提醒采用本地 HH:mm，周一为星期位 0。DispatcherTimer 每秒检查当前分钟；固定时刻只触发运行后、任务新建/修改后到达的时刻。L3 不全面补发已经错过的固定分钟。

ReminderKey 包含任务、本地日期、时间和 Fixed/Repeat/Snooze 类型。进程内去重最多保留近七天键；SQLite 保存最近展示时间、下一追加和每日次数，防止正常延期到期后同分钟固定时间再次弹出。已可见的事项保持一张卡片，不叠加窗口。显示窗口后才提交进度，异常退出发生在显示/提交之间仍可能重复；完整投递账本和时钟变化在 L4。

当前分钟内桌面不可用时不消费提醒键；恢复得足够早可以展示该分钟，较晚恢复不保证补提醒。使用 UOI_IO 只查询当前线程所属桌面是否接收输入，不切换桌面、不订阅键盘。显式退出停止计时，隐藏主窗不停止。

下次时间按所选星期查找未来七天；今天已检查的等待任务跳过今天，待办理任务不受旧等待检查影响。DST 不存在的本地时间跳过；重复的本地时间使用同一个本地键并选较早偏移对应时刻，不声称已经完成 L4 所有时间变化策略。

## 追加与延期

- 默认 09:00 固定提醒后，09:30、10:00、10:30 追加。间隔可设 5—1440 分钟，每个任务每天上限 0—24 次；0 关闭追加。多个固定时间共用预算，固定时间不占追加次数。到达上限后，后续固定时间仍有效，但不会重新获得追加次数。
- 固定时间和追加撞点，只处理固定时间，重设追加锚点且不扣次数。定时器稍迟时只展示一次，下一追加沿原计划间隔推进到未来，跳过的间隔不补成一串弹窗、不按迟到的每秒 tick 漂移。
- 10/30/60 分钟延期覆盖期间的所有自动时刻，不扣追加次数。到期提示一次，再按剩余预算追加。显式延期可跨午夜、跨未选择的星期；自动追加仅限所选星期的本地当天，不把昨日追加拖到次日。
- 延期、当天已用预算、下一追加和最近展示时间写入 reminder_progress，正常重启恢复。已经过期的显式延期展示一项；同日到期追加展示一项；过期的昨日自动追加跳过，等新的固定时间。完整多日补偿留在 L4。
- 关闭提醒、打开链接及无结果的 tick 不重设计划。今日检查取消当天剩余检查；确认开放从确认时间重算追加，保留当天已用预算。编辑、暂停、完成、归档、撤销和恢复会清除旧延期/追加，编辑/恢复等待未来固定时刻，不因反复编辑增加预算。状态、事件、检查及进度清理同一事务。

## 日期型截止

截止是本地 DateOnly，截止当天整日标记“今天截止”，下一本地日期标记“已逾期 N 天”。逾期、今天、未来日期、未知日期依次排序；不会自动确认开放、完成、隐藏或修改追加间隔。暂停/完成/归档保留日期但不显示活动催办优先级。

## 每天检查与办理

“尚未开放”与“已开放”使用不同结构化结果，和任务/操作事件同一事务保存。尚未开放保持 Waiting 并抑制本日检查；次日重算。确认开放转 Ready，不设置 CompletedAt。处于提醒窗口内的事项会原位换为待办理，直到明确完成或收起。主窗也能记录检查、确认开放。

打开链接只将重新校验过的 http/https URI 交给默认浏览器，拒绝本地文件、命令和 URL 内凭据；不运行脚本，不读取平台页面。浏览器启动失败显示具体错误，不写检查记录；调度错误不覆盖已有操作错误。关闭实际提醒不更新业务状态；同分钟不立即重弹，后续固定时间和剩余追加仍会提示。

## 窗口与失败

实际提醒独立于演示窗口和主窗口，置顶、ShowActivated=false、不自动消失，支持合并列表滚动。主窗隐藏不关闭实际提醒。事件处理使用显示时的任务修订号，旧内容不能覆盖新编辑；暂停/完成/归档会从可见提醒中移除，显示剩余事项。

只读、锁定、损坏、更高版本和缺失字段等异常必须可见，不得确认虚假成功。初始化未成功时禁止提醒快照和任务写入。任务/检查快照在一个读事务获取，检查与状态在写事务提交。

## 实测与复现

运行 scripts/test-core.ps1 验证本地日期、星期、DST、每日抑制、事务和升级；scripts/test-shell.ps1 通过可替换时钟验证真实窗口按钮。scripts/test-reminder-live.ps1 使用生产 1 秒计时器、隔离任务库和下一实际分钟，不改系统时间，也不访问私人任务。必须在本地可交互桌面运行，不能将模拟时钟当作实际按时投递。

L3 的 2026-10-22 20:46（Asia/Shanghai）实测在 20:46:01.026 展示，两项合并，前台句柄保持不变。这是一轮固定时间的本机观察；追加/延期使用受控时钟及独立进程恢复验证，未等待真实 30 分钟追加。不能当作所有负载、独占全屏、锁屏恢复或 L5 连续试用通过。
