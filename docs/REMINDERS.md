# L2 调度、操作与当前边界

## 固定时间

ReminderPlanner 是纯核心逻辑，接收当前 UTC 时刻、本地时区、程序开始观察时刻和任务/检查快照。提醒时间采用本地 HH:mm，周一为星期位 0。DispatcherTimer 每秒在 WPF 队列检查当前本地分钟；只触发程序运行以后、任务新建/修改以后到达的时刻。跳过的历史分钟不在 L2 补发。

同一任务/本地日期/固定时间构成一个 ReminderKey，当前进程的集合防止同一分钟重复弹窗，最多保留近七天键。不同事项或后续固定时间仍可触发；已经可见的同一事项保持一张卡片，不叠加窗口。完整跨重启去重、系统时间回拨和休眠恢复属于 L4。

当前分钟内桌面不可用时不消费提醒键；恢复得足够早可以展示该分钟，较晚恢复不保证补提醒。使用 UOI_IO 只查询当前线程所属桌面是否接收输入，不切换桌面、不订阅键盘。显式退出停止计时，隐藏主窗不停止。

下次时间按所选星期查找未来七天；今天已检查的等待任务跳过今天，待办理任务不受旧等待检查影响。DST 不存在的本地时间跳过；重复的本地时间使用同一个本地键并选较早偏移对应时刻，不声称已经完成 L4 所有时间变化策略。

## 每天检查与办理

“尚未开放”与“已开放”使用不同结构化结果，和任务/操作事件同一事务保存。尚未开放保持 Waiting 并抑制本日检查；次日重算。确认开放转 Ready，不设置 CompletedAt。处于提醒窗口内的事项会原位换为待办理，直到明确完成或收起。主窗也能记录检查、确认开放。

打开链接只将重新校验过的 http/https URI 交给默认浏览器，拒绝本地文件、命令和 URL 内凭据；不运行脚本，不读取平台页面。浏览器启动失败显示错误，不写检查记录。关闭实际提醒也不更新业务状态；同分钟不立即重弹，后续固定时间仍会提示。30 分钟追加、上限和稍后处理在 L3 接入。

## 窗口与失败

实际提醒独立于演示窗口和主窗口，置顶、ShowActivated=false、不自动消失，支持合并列表滚动。主窗隐藏不关闭实际提醒。事件处理使用显示时的任务修订号，旧内容不能覆盖新编辑；暂停/完成/归档会从可见提醒中移除，显示剩余事项。

只读、锁定、损坏、更高版本和缺失字段等异常必须可见，不得确认虚假成功。初始化未成功时禁止提醒快照和任务写入。任务/检查快照在一个读事务获取，检查与状态在写事务提交。

## 实测与复现

运行 scripts/test-core.ps1 验证本地日期、星期、DST、每日抑制、事务和升级；scripts/test-shell.ps1 通过可替换时钟验证真实窗口按钮。scripts/test-reminder-live.ps1 使用生产 1 秒计时器、隔离任务库和下一实际分钟，不改系统时间，也不访问私人任务。必须在本地可交互桌面运行，不能将模拟时钟当作实际按时投递。

2026-10-22 20:09（Asia/Shanghai）的实测，在 20:09:01.062 展示，两项合并，前台句柄保持不变。这是一轮本机观察，不是所有电脑负载、独占全屏或锁屏恢复的保证。长期和真人使用验收留在 L5。
