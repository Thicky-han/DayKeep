# DayKeep 回环时钟标记

2026-10-22，按用户“先给 DayKeep 换个 logo”要求，替换 L0/L1 的日出候选。新标记由深青绿圆角底、暖白回环时钟和金色提醒点组成：回环表示每日继续，时针表示固定时间，提醒点表示仍需关注。颜色 #286F64 → #174C47、#F8F3DF、#E9B56D。

SVG 为可编辑矢量源；generate-icon.ps1 依据同样的几何与配色生成 256 像素透明 PNG 和含 16/24/32/48/64/128/256 帧的 ICO，各尺寸先以 4 倍渲染再缩小。程序和托盘共用内嵌 ICO；主窗和提醒预览共用 PNG，避免分别手绘出现差异。桌面快捷方式使用成品目录单独的 DayKeep.ico，避免沿用旧 exe 的图标缓存。

所有素材为本项目原创矢量/绘制代码，未复制 NameFirst、uBlacklist 或第三方商标，按仓库 AGPL-3.0-only。已在当前预览应用此方案；不将本轮换图标指令描述为用户已经审阅并最终定稿，L6 仍可做最终品牌审阅。旧日出标记保留在 Git 历史中。
