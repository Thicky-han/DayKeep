毎日少しずつ、完了するまで。特許料金の支払い受付など、まだ利用できず毎日確認したい用事のための Windows ローカル通知アプリです。「今日確認した」と「用事を完了した」を区別します。プレリリース **0.6.0-l6** は管理者の承認を得て公開済みです。文書は9言語、**アプリの表示言語は現在、簡体字中国語のみ**です。3日間の実利用試験は未完了です。コード署名はありません。

## インストールと更新

DayKeep-0.6.0-l6-win-x64.zip をすべて展開してください。Windows x64 用でランタイムを同梱し、SDK は不要です。ZIP 内からの実行や exe だけのコピーは避けてください。入手元と SHA256SUMS を確認し、DayKeep.exe を開けばポータブル利用できます。Windows が不明な発行元を表示する場合があります。

Install.cmd は管理者権限なしで LocalApplicationData/Programs/DayKeep/0.6.0-l6 に配置し、デスクトップとスタートメニューに DayKeep を作成します。PowerShell の実行ポリシー例外はそのプロセスだけです。ログイン起動は有効にしません。旧版のフォームを保存し、トレイの「退出日守」で終了してから更新してください。× は非表示にするだけです。バージョン別フォルダーを使い、旧版や不明なフォルダーを上書きしません。同一版の再インストールは同じ完全なファイルだけを受け付けます。初回に DB を schema 5 へトランザクション移行し、L1–L4 は読めなくなります。先にバックアップしてください。

## 最初の通知を作る

1. 「＋ 新建任务」を押し、「特許の支払い入口を確認」などの名前を入力します。受付待ちは「等待条件」、すぐ実行できる用事は「普通待办」です。
2. 任意で http/https の完全な URL とメモを追加します。認証情報入り URL は不可、期限不明なら空欄にします。
3. `09:00` または `09:00, 14:30` を入力します。24時間 HH:mm、最大8時刻、曜日は1日以上選択します。
4. 未処理なら既定で30分間隔、現地日付ごとに追加3回まで。間隔5–1440分、上限0–24回。0でも固定時刻の通知は残ります。
5. 期限は `yyyy-MM-dd`。当日・期限超過を強調しますが、自動完了しません。保存し、トレイで動かしておきます。

## 毎日の操作

| 画面のボタン | 操作の意味 |
| --- | --- |
| 打开平台 | ブラウザーを開くだけ。確認・完了を記録しない |
| 今日已检查，尚未开放 | 未開放を記録し、その日の確認通知を止める。次の指定日に再開 |
| 已开放，转待办理 | 開放を記録し、手続き待ちとして追跡を続ける |
| 10 分钟后 / 30 分钟后 / 1 小时后 | その用事を10/30/60分延期。間の固定・追加通知を抑え、再起動後も維持 |
| 确认已完成 | 本当に手続きが終わったら押す。通知停止、取り消し可能 |

複数の用事は最前面の1つのスクロール可能な通知にまとまり、キーボードフォーカスを要求せず数秒で消えません。閉じても未完了なら追加します。既定では09:00の後09:30、10:00、10:30。固定時刻と重なる追加は統合し、延期は追加回数を消費しません。

「暂停」は状態を残して一時停止、「归档」は削除せず保管します。各フィルターから復帰でき、「撤销完成」は再起動後も完了前の状態と一時停止設定を戻します。

## デスクトップと履歴

「窄窗 / 展开」で幅、「置顶」で最前面を切り替えます。透明度は背景だけです。× / Esc でトレイへ、Ctrl+Alt+D・トレイクリック・再実行で復帰。ショートカット競合時はトレイを使います。非表示はフォームを保ち、フォームを閉じると下書きを破棄します。完全終了は「退出日守」。停止中や電源オフでは表示できません。

復帰・再起動・ロック解除時は各用事の最新の有効な未通知時刻だけを集約します。未収納の通知は復元、収納済みは重複しません。他のアプリの全画面や利用不可デスクトップでは延期します。「登录 Windows 后在托盘运行」は既定オフで、フォルダー変更後は再確認してください。Windows が起動を遅延・無効化することもあります。

「历史与备份」（小型表示では下部「检查历史与备份」）で、完了・保管済みも含む用事、開始/終了日、名前/操作/確認メモを選び「查询」。両端の日付を含み、空欄は無制限、「重置」で解除します。最新200件を表示し、それ以前は条件を絞ります。現在の用事名を表示し、確認日は元の現地日付、時刻は現在のタイムゾーンです。

## バックアップと復元

1. 「备份与恢复 → 导出完整备份」で新しい `.daykeep.json` に保存します。既存ファイルを上書きせず、未保存フォームは含みません。
2. 用事・履歴・完了取り消し・保管・延期・日別回数・配信記録を含み、外観とログイン起動は除外します。平文なので安全に保管し、信頼できるものだけを読み込みます。
3. 「选择备份并预览」で日時と件数を確認。「合并」は本機にない GUID の用事だけ追加。同 ID の全記録は本機を保持し、同名別 ID は別件です。
4. 「替换」はバックアップ全体に戻し、含まれない本機の用事を除きます。フォームを保存/閉じ、影響を確認してチェックを入れ実行します。方式変更で確認は解除されます。
5. プレビュー後に用事や通知記録が変わったら「重新预览」。書き込み前に tasks.db 隣の Recovery へ現データを自動保存し、成功後パスを表示します。
6. 取り消すにはその復元ファイルをプレビューして置換します。復元ファイル保存失敗なら DB を変更せず、SQL 失敗はロールバック。不正・破損・非対応版・検査値不一致は拒否します。

上限64 MiB、20,000用事、合計200,000記録。SHA-256 は破損検出用で、暗号化・出所認証ではありません。復元した未収納通知がすぐ出ることがあります。[形式の詳細（中国語）](docs/BACKUP_FORMAT.md)。

## データ・削除・問題解決

データは現ユーザー LocalApplicationData/DayKeep の tasks.db と ui-settings.json。手動コピーは終了後、付随ファイルを含むフォルダー全体を保存します。破損時は原フォルダーをコピー・改名して残し、新しい空 DB に信頼できるバックアップを戻します。

ログイン起動をオフにして保存・終了し、**インストール先の Uninstall.cmd** でその版だけ削除します。私用データと他版は保持し、追加・変更ファイルがあれば停止します。ポータブル版はアンインストーラー不要です。

通知がなければトレイ、時刻/曜日、停止/保管/完了、当日確認、全画面を確認します。旧版が出るならトレイから旧版を終了。保存失敗は原本を残して権限・空き容量・占有を確認し、古いプレビューは再作成します。アカウント、テレメトリー、ページ取得、パスワード保存、自動支払いはありません。

3日間の実利用、実機の睡眠/ロック、多画面/混在 DPI、排他的全画面は未検証項目を残しています。L4 最終の実時間観測はデスクトップ判定で表示延期となりました。模擬試験を実機合格としません。
