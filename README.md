# DayKeep · 日守

![DayKeep 回环时钟 Logo](assets/brand/daykeep-mark.png)

**每天一步，直到完成。** 面向 Windows 的轻量桌面任务与提醒工具，帮助持续跟进暂时无法办理、需要反复查看的事情。

当前版本 **0.4.0-l4：恢复补提醒与桌面可靠性**。支持重启/恢复后的汇总补提醒、持久投递去重和可选登录启动；保留固定时间、未处理追加、10/30/60 分钟延期、每日检查与截止日期高亮。沿用已认可的回环时钟 Logo、半透明背景、窄窗、托盘与 Ctrl+Alt+D。

**提醒需要程序运行且电脑处于唤醒、桌面可用状态。** 默认每天 09:00，未处理每 30 分钟追加，每个任务每天最多额外 3 次。间隔和上限可改，上限 0 关闭自动追加。多个固定时间共用当天追加上限；同时到期合并为一个置顶窗口，不主动激活键盘焦点。

## 打开与使用

本地自包含预览：打开 dist/l4-win-x64/DayKeep.exe，保留整个文件夹，无需安装 SDK。桌面 DayKeep 日守快捷方式指向此版本。若旧窗口仍在运行，先保存表单、从托盘退出，再重新打开加载 L4。当前仅本地交付，未公开到 GitHub，也不是正式签名安装包。

1. 点击“＋ 新建任务”，输入名称并选择普通待办或等待条件。
2. 填写固定时间、星期、追加间隔与每天上限，可加平台链接和备注；截止日期未知时留空。
3. 保持日守在托盘运行，到点查看提醒；“打开平台”只打开网页，不记录检查或完成。
4. 等待条件的事项可选择“今日已检查，尚未开放”，停掉当日检查提醒；或“已开放，转待办理”，继续保留直到明确完成。
5. 从“已完成”分类撤销完成，恢复完成前的业务状态和暂停设置；重启后仍可撤销。归档也可恢复。
6. 关闭主窗 × / Esc 收起到托盘，继续提醒；Ctrl+Alt+D 或托盘唤回。彻底退出使用托盘右键菜单。

关闭提醒窗口后，仍按规则追加；“10 分钟后 / 30 分钟后 / 1 小时后”会覆盖期间的固定与追加提醒。延期、当天已用次数和下一追加时间保存在本机，重启可恢复；显式延期不消耗自动追加上限。“今日已检查”取消当天检查提醒，次日按所选星期恢复。日期型截止按本地日界线判断，过期继续追踪，不会自动完成。

重启、恢复或解锁后，每个任务只汇总最近一个有效固定时刻，卡片显示原定时间，多天遗漏不会逐次重放。显示前保存投递与下一计划，未收起的窗口重启可恢复，已收起的时刻不重弹；每天次数在日期回拨后也保留。桌面不可用或其他程序占据全屏时暂缓，退出全屏后继续。

“外观与操作”可开启“登录 Windows 后在托盘运行”，默认关闭。后台启动保持主窗隐藏；手动再次打开唤回同一窗口。退出会停止提醒；开启登录启动时，下次登录再运行。窗口适配当前显示器工作区和 DPI，窄屏自动切为窄窗。真实睡眠/解锁、物理多屏和独占全屏仍需对应实机验收，详见阶段报告。

任务、检查记录模型、状态操作记录与外观保存在当前用户 LocalApplicationData 的 DayKeep 文件夹。读写错误会提示并保留原文件，不会自动清空数据库。导出与恢复界面留在 L5。详细步骤见 [使用说明](INSTALL.md)。

## 开发运行

Windows x64、PowerShell 7、global.json 固定的 .NET 10 SDK：

```powershell
pwsh -File scripts/bootstrap.ps1   # 已有对应 SDK 可跳过
pwsh -File scripts/build.ps1
pwsh -File scripts/run.ps1
```

SDK 从微软官方来源下载并验证 SHA-512，只装入忽略的 .tools。应用包从 NuGet 官方源还原，准确版本与内容哈希在各项目 packages.lock.json 中，默认锁定还原。

```powershell
pwsh -File scripts/check.ps1
pwsh -File scripts/test-core.ps1
pwsh -File scripts/test-shell.ps1
pwsh -File scripts/test-reminder-live.ps1  # 等待下一实际分钟，仅本地桌面运行
pwsh -File scripts/publish-preview.ps1
pwsh -File scripts/create-shortcut.ps1
# 单实例检查使用隔离数据和命名对象，不影响已有日守。
pwsh -File scripts/test-instance.ps1
git diff --check
```

核心检查使用真实 SQLite 文件，包含独立进程投递/延期/次数恢复、schema-1/2/3 升级、日期与时间变化。WPF 受控检查验证真实按钮、桌面恢复、窗口位置和启动设置；真实时钟另测下一实际分钟。启动项适配器使用测试注册表键，单实例用三个实际进程验证后台/手动打开和正常退出。报告和合成任务保存在忽略的 .cache，不读取私人任务，不代替实际睡眠、多屏或连续多日试用。
