## 切換介面語言

主視窗頂部的 **Language / 语言** 下拉選單在完整與窄窗模式均可見，不必進入設定。以語言本身的名稱選取：**简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Português**。

選取後主視窗、事項表單、提醒、歷史與備份等應用文字立即更新，並儲存於本機，下次啟動沿用。首次使用與舊版尚無語言設定時預設簡體中文；儲存失敗會顯示錯誤並保留原語言，不會顯示虛假成功。

事項名稱、備註、連結及原始記錄不自動翻譯。切換不改變電腦本地時區、星期或提醒時刻；仍用 24 小時 `HH:mm`、截止日 `yyyy-MM-dd`。下文簡體按鈕名供對照，實際顯示所選語言的文字。[語言與儲存規則](docs/LANGUAGES.md)

## 安裝與更新

1. 完整解壓 DayKeep-0.7.0-beta.1-win-x64.zip；Windows x64，內含執行階段，不需 SDK。不要在 ZIP 內開啟或只複製 exe。舊版 0.6.0-l6 的使用方式相同，但沒有語言切換。
2. 可直接執行 DayKeep.exe；請核對來源及 SHA256SUMS，Windows 可能顯示未知發行者。
3. 雙擊 Install.cmd 安裝至目前使用者 LocalApplicationData/Programs/DayKeep/0.7.0-beta.1，建立 DayKeep 桌面與開始功能表捷徑，不需管理員。PowerShell 執行原則例外僅限該程序。
4. 更新前匯出備份、儲存表單，從舊版系統匣「退出日守」完全結束；× 只是隱藏。新版使用獨立版本目錄，舊版保留；未知或修改過的目錄、捷徑不會任意覆寫。同版本重裝須檔案一致完整。
5. 安裝不開啟登入啟動，也不強制關閉舊版。首次執行以交易升級至 schema 5，L1—L4 無法讀取升級後資料庫。

## 建立第一個事項

點「＋ 新建任务」，名稱填「查看專利繳費入口」。未開放選「等待条件」，已可直接辦理選「普通待办」。可填完整 http/https 連結及備註，含帳密的網址拒絕；未知截止日期留空。

時間填 `09:00` 或 `09:00, 14:30`，24 小時 HH:mm，最多八個不同時間；至少選一天。預設未處理每 30 分鐘追加，每本地日最多額外三次。間隔可設 5—1440 分鐘，上限 0—24；0 關閉追加，固定提醒保留。已知截止日填 `yyyy-MM-dd`，今天/逾期高亮，不會自動完成。儲存並保持系統匣執行。

## 每日跟進流程

| 按鈕（簡體對照） | 用途與結果 |
| --- | --- |
| 打开平台 | 只開預設瀏覽器，不算已檢查或完成 |
| 今日已检查，尚未开放 | 儲存檢查，停止當天等待檢查提醒，下個選定日繼續 |
| 已开放，转待办理 | 記錄開放、保留事項，持續跟進辦理 |
| 10 分钟后 / 30 分钟后 / 1 小时后 | 延後此事項，覆蓋期間固定/追加，重啟仍有效 |
| 确认已完成 | 確實辦妥再按；停止提醒，可撤銷 |

多件到點合併成置頂視窗，不主動搶鍵盤，也不數秒後消失。關閉提醒仍按規則追加；預設 09:00 後為 09:30、10:00、10:30。固定與追加撞點合併，延後不扣追加額度。今日檢查取消當天剩餘等待提醒。

「暂停」保留狀態，「恢复跟进」繼續未來時刻；歸檔可在「已归档」恢復，沒有永久刪除。從「已完成」按「撤销完成」恢復原狀態與暫停標誌，重啟後也可撤銷。

## 桌面操作

窄窗/展開、置頂可切換；透明度只影響背景。× 或 Esc 收至系統匣；Ctrl+Alt+D、系統匣點擊或再次執行喚回。熱鍵衝突用系統匣。隱藏保留表單，關閉表單捨棄草稿。「退出日守」才完全停止；停機期間不能顯示提醒。

重啟/恢復/解鎖每件僅彙總最近有效遺漏時刻，多日不連續重播；未收起投遞恢復，已收起不重複。桌面不可用或其他程式全螢幕時暫緩。「登录 Windows 后在托盘运行」預設關閉，換目錄後請重新核對；Windows 也可能延後/停用。

## 歷史與備份教學

「历史与备份」或窄窗底部「检查历史与备份」開啟工具窗。可選事項（含完成/歸檔）、包含起止當天的日期，搜尋名稱/操作/檢查備註，按「查询」；「重置」清空。最新 200 筆可見，更多時縮小範圍，完整資料仍匯出。名稱為目前名稱，檢查保留原本地日期，時間依目前時區顯示。

1. 「备份与恢复 → 导出完整备份」存新 `.daykeep.json`，不覆寫舊檔，不含未儲存表單。
2. 包含任務、歷史、完成撤銷、歸檔、延後、日額度及投遞，不含介面語言、外觀或登入啟動；匯入不改變目前語言。明文檔須妥善保管，只匯入可信來源。
3. 「选择备份并预览」核對時間與數量。「合并」僅新增本機沒有的 GUID；同 ID 保留本機整組資料，同名不同 ID 不合併。
4. 「替换」恢復整份備份，移除備份沒有的本機事項。先儲存/關閉表單，核對影響後勾選確認；改模式或介面語言會重設勾選。切換語言保留所選檔案、模式與凍結預覽，需以新語言重新核對影響。
5. 預覽後資料或投遞改變需「重新预览」。匯入前自動將目前資料存至 tasks.db 旁 Recovery，成功後顯示路徑。
6. 撤回匯入：選該恢復檔，預覽後替換匯入。寫恢復檔失敗不改庫，SQL 錯誤回復交易；損壞/版本/校驗不符拒絕。

上限 64 MiB、20,000 事項、合計 200,000 記錄。SHA-256 只檢測損壞，不加密或認證來源。恢復未收起提醒可能立即顯示。[完整契約](docs/BACKUP_FORMAT.md)。

## 資料、解除安裝與排錯

資料位於目前使用者 LocalApplicationData/DayKeep（tasks.db、ui-settings.json）。更新程式不移除資料。手動備份先完全退出，複製完整目錄及附屬檔；損壞庫保留原目錄，備份並改名後重開空庫，再匯入可靠備份。

關閉登入啟動，儲存並從系統匣退出，執行**安裝目錄內 Uninstall.cmd**，只移除該版本清單檔及其捷徑，私人資料和其他版本保留；額外/修改檔會阻止移除。免安裝目錄無需解除安裝程序。

沒有提醒時核對系統匣、時間/星期、暫停/歸檔/完成、今日檢查與全螢幕；舊版仍顯示時先完全退出它。儲存/匯入錯誤保留檔案，檢查權限、空間、佔用並重新預覽。

三天實際使用、真實休眠/鎖屏、多螢幕/混合 DPI、獨佔全螢幕仍待實機驗收；L4 最後實際分鐘觀測因桌面門控未顯示，受控測試不能代替。無帳號、遙測、網頁擷取、密碼或自動繳費。
