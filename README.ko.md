매일 한 걸음, 완료할 때까지. 특허 납부 창구처럼 아직 열리지 않아 날마다 확인해야 하는 일을 위한 Windows 로컬 알림 앱입니다. 오늘 확인한 것과 작업 전체의 완료를 구분합니다. 현재 공개 사전 출시판 **0.7.0-beta.1**은 유지관리자의 공개 승인을 받았으며 9개 화면 언어와 찾기 쉬운 언어 선택기를 추가합니다. 위 링크는 이번 버전의 프로그램, 소스와 체크섬입니다. 실제 빌드, 패키지와 공개 검증 진행 상황은 [언어 업데이트 보고서](LANGUAGE_UPDATE_REPORT.md)를 참고하세요. 이전 **0.6.0-l6**는 중국어 간체 화면만 지원하며 원래 첨부 파일과 태그는 유지됩니다. 승인된 패키지 안의 고정 문서는 패키징 당시 후보 상태를 기록합니다. 3일 실제 사용 검수는 대기 중입니다. 코드 서명은 없습니다.

## 화면 언어 바꾸기

메인 창 위쪽의 **Language / 语言** 목록을 여세요. 일반 창과 작은 창 모두 항상 보이며 설정 페이지에 들어갈 필요가 없습니다. 각 언어는 고유 이름으로 표시됩니다: **简体中文, 繁體中文, English, 日本語, 한국어, Français, Deutsch, Español, Português**.

선택하면 메인 창, 작업 양식, 알림, 기록, 백업 도구의 앱 문구가 즉시 바뀌고 이 컴퓨터에 저장되어 다음 실행 때 복원됩니다. 처음 사용하거나 이전 버전에 저장된 언어가 없으면 중국어 간체가 기본입니다. 저장 실패 시 오류를 표시하고 기존 언어를 유지합니다.

직접 입력한 작업 이름, 메모, 링크와 원래 기록은 번역하지 않습니다. 언어를 바꿔도 컴퓨터의 현지 시간대, 요일과 알림 시각은 바뀌지 않습니다. 시간은 24시간 `HH:mm`, 마감일은 `yyyy-MM-dd`를 사용하세요. 아래 중국어 버튼명은 대조용이며 앱에는 선택한 언어의 문구가 표시됩니다. [언어와 저장 규칙](docs/LANGUAGES.md)

## 설치와 업데이트

DayKeep-0.7.0-beta.1-win-x64.zip 전체를 압축 해제하세요. 이전 0.6.0-l6 ZIP도 사용법은 같지만 언어 선택기는 없습니다. Windows x64용 런타임이 포함되어 SDK가 필요 없습니다. ZIP 안에서 실행하거나 exe만 복사하지 마세요. 출처와 SHA256SUMS를 확인한 뒤 DayKeep.exe를 실행하면 포터블로 사용할 수 있습니다. Windows가 알 수 없는 게시자로 표시할 수 있습니다.

Install.cmd는 관리자 권한 없이 LocalApplicationData/Programs/DayKeep/0.7.0-beta.1에 설치하고 바탕 화면/시작 메뉴에 DayKeep 바로 가기를 만듭니다. PowerShell 실행 정책 예외는 해당 프로세스에만 적용됩니다. 로그인 시작은 자동으로 켜지지 않습니다. 업데이트 전에 백업을 내보내고 양식을 저장한 뒤 이전 버전 트레이의「退出日守」로 종료하세요. ×는 숨기기입니다. 버전별 폴더를 사용해 이전 버전과 알 수 없는 파일을 보존합니다. 같은 버전 재설치는 동일하고 온전한 파일만 허용합니다. 첫 실행은 DB를 schema 5로 트랜잭션 업그레이드하며 L1–L4는 업그레이드된 DB를 읽지 못합니다.

## 첫 작업 만들기

1. 「＋ 新建任务」에서 “특허 납부 창구 확인”을 입력합니다. 조건을 기다리면「等待条件」, 지금 처리 가능하면「普通待办」를 선택합니다.
2. 선택 사항으로 완전한 http/https 링크와 메모를 입력합니다. 계정 정보가 담긴 URL은 거부하며, 모르는 마감일은 비워 둡니다.
3. `09:00` 또는 `09:00, 14:30`처럼 24시간 HH:mm을 사용합니다. 최대 8개 시각, 요일은 하나 이상 선택합니다.
4. 미처리 시 기본 30분마다 하루 추가 3회입니다. 간격은 5–1440분, 한도는 0–24회. 0은 자동 추가만 끄며 고정 시각은 유지합니다.
5. 마감일은 `yyyy-MM-dd`. 오늘/기한 초과를 강조하되 자동 완료하지 않습니다. 저장하고 트레이에서 실행을 유지합니다.

## 매일 처리하기

| 버튼(중국어 대조) | 의미 |
| --- | --- |
| 打开平台 | 브라우저만 열며 확인/완료를 기록하지 않음 |
| 今日已检查，尚未开放 | 아직 열리지 않았음을 기록, 오늘 확인 알림 중지, 다음 지정 요일 재개 |
| 已开放，转待办理 | 열렸음을 기록하고 처리 대기로 계속 추적 |
| 10 分钟后 / 30 分钟后 / 1 小时后 | 해당 작업 10/30/60분 미루기. 중간 고정/추가 알림을 덮고 재시작 후 유지 |
| 确认已完成 | 실제로 처리했을 때 완료. 알림 중지, 취소 가능 |

여러 작업은 하나의 스크롤 가능한 맨 위 창에 모이며 키보드 포커스를 요청하지 않고 잠깐 뒤 사라지지도 않습니다. 닫기는 완료가 아닙니다. 기본 09:00 이후 09:30, 10:00, 10:30에 추가합니다. 고정 시각과 겹치면 합치며 추가 횟수를 더 쓰지 않습니다. 미루기는 자동 추가 한도를 소비하지 않고, 오늘 확인은 그날 나머지 대기 확인 알림을 취소합니다.

「暂停」는 상태를 보존한 일시정지,「归档」는 삭제 없는 보관입니다. 각 필터에서 복원할 수 있습니다.「撤销完成」는 재시작 후에도 완료 전 상태와 일시정지를 되돌립니다.

## 바탕 화면과 기록

「窄窗 / 展开」로 폭,「置顶」으로 맨 위 고정을 바꿉니다. 투명도는 배경에만 적용됩니다. ×/Esc로 트레이에 숨기고 Ctrl+Alt+D, 트레이 클릭, 다시 실행으로 엽니다. 단축키 충돌 시 트레이를 쓰세요. 숨기기는 양식을 보존하지만 양식을 닫으면 초안을 버립니다. 완전 종료는「退出日守」이며 앱 중지/전원 꺼짐 중에는 표시할 수 없습니다.

재시작/절전 복귀/잠금 해제 시 각 작업의 가장 최근 유효 누락 시각만 합칩니다. 미닫음 알림은 복구, 닫은 시각은 중복하지 않습니다. 사용 불가 데스크톱/다른 앱 전체 화면에서는 보류합니다.「登录 Windows 后在托盘运行」는 기본 꺼짐이며 경로 변경 후 다시 확인하세요. Windows가 지연/비활성화할 수도 있습니다.

「历史与备份」또는 작은 창 하단「检查历史与备份」에서 작업(완료/보관 포함), 시작/종료 날짜, 이름/동작/확인 메모를 골라「查询」. 날짜는 양 끝 포함, 빈칸은 제한 없음,「重置」는 초기화입니다. 최신 200건이 보이며 이전 기록은 범위를 좁히세요. 백업은 전체 기록을 포함합니다. 이름은 현재 이름, 확인 날짜는 원래 현지 날짜, 시각은 현재 시간대입니다.

## 백업·복원·가져오기 취소

1. 「备份与恢复 → 导出完整备份」에서 새 `.daykeep.json`으로 저장합니다. 기존 파일을 덮지 않고 미저장 양식은 제외합니다.
2. 작업, 기록, 완료 취소, 보관, 미루기, 일일 횟수와 전달 상태를 포함합니다. 화면 언어/외관/로그인 시작은 제외하며 가져오기는 현재 언어를 바꾸지 않습니다. 평문이므로 안전하게 보관하고 신뢰하는 파일만 가져오세요.
3. 「选择备份并预览」로 날짜/개수를 확인합니다.「合并」는 로컬에 없는 GUID만 추가하고 같은 ID의 모든 로컬 기록을 보존합니다. 이름만 같은 별도 ID는 합치지 않습니다.
4. 「替换」는 전체 백업을 복원하고 백업에 없는 로컬 작업을 제거합니다. 양식을 저장/닫고 영향을 확인한 뒤 체크해 실행합니다. 모드나 화면 언어를 바꾸면 체크가 해제됩니다. 언어 변경은 선택한 파일, 모드와 고정된 미리 보기를 유지하며 새 언어로 영향을 다시 확인해야 합니다.
5. 미리 보기 후 데이터/알림이 바뀌면「重新预览」. 기록 전에 tasks.db 옆 Recovery에 현재 데이터를 자동 백업하며 성공 후 경로를 표시합니다.
6. 취소하려면 그 복구 파일을 미리 보고 교체합니다. 복구 파일 저장 실패는 DB를 바꾸지 않고 SQL 실패는 롤백합니다. 손상/버전/검증 불일치를 거부합니다.

한도: 64 MiB, 작업 20,000개, 전체 200,000기록. SHA-256은 손상 감지용이며 암호화/출처 인증이 아닙니다. 복구된 미닫음 알림이 즉시 뜰 수 있습니다.[상세 계약](docs/BACKUP_FORMAT.md).

## 데이터·제거·문제 해결

현재 사용자 LocalApplicationData/DayKeep에 tasks.db, ui-settings.json을 보관합니다. 수동 복사는 종료 후 관련 파일을 포함한 전체 폴더로 하세요. 손상 DB는 원본을 복사/이름 변경해 보존하고 새 빈 DB에서 신뢰 백업을 복원합니다.

로그인 시작을 끄고 저장/트레이 종료 후 **설치된 버전 폴더의 Uninstall.cmd**를 실행하세요. 그 버전의 변경되지 않은 목록 파일/해당 바로 가기만 제거하고 사용자 데이터와 다른 버전은 보존합니다. 추가/수정 파일이 있으면 중지합니다. 포터블 폴더는 설치 제거가 필요 없습니다.

알림이 없으면 트레이, 시각/요일, 일시정지/보관/완료, 오늘 확인과 전체 화면을 확인하세요. 이전 버전이 뜨면 먼저 그 트레이에서 종료합니다. 저장 오류는 원본을 보존하고 권한/공간/점유를 점검하며 오래된 미리 보기는 갱신합니다. 계정, 원격 측정, 웹 수집, 비밀번호 저장, 자동 납부 기능은 없습니다.

실제 3일 사용, 실제 절전/잠금, 다중 모니터/혼합 DPI와 독점 전체 화면은 검수가 남았습니다. L4 마지막 실제 분 단위 관찰은 데스크톱 판정으로 보류됐습니다. 모의 검사를 실제 합격으로 간주하지 않습니다.
